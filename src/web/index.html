Usage bars

Applies to the dashboard gauges and to the bars in the menu bar dropdown.

Menu bar plate

The menu bar sits on your wallpaper, which macOS repaints and tints on its own — no fixed text colour survives that. Giving the item its own opaque plate makes the contrast something we control and measure: the text colour is derived from the plate, never chosen, so it is always readable.

Polling & alerts

The usage endpoint publishes no rate limit, so this errs on the quiet side. It does not cost you responsiveness: a session starting here takes a reading straight away, and a limit resetting schedules its own. The idle rate only governs how quickly usage from another machine shows up.

Claude Usage Bar

Live Claude usage and session monitor. Limit percentages come from Anthropic's own usage endpoint using the OAuth token Claude Code already holds; everything else is read from the transcripts on this machine. Nothing is sent anywhere.
